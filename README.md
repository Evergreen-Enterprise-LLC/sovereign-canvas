# Sovereign Canvas

Public, secret-free preview canvas for apps generated by Sovereign X.

## Contract

- Every generated result lives on an isolated `comm/<8hex>` branch.
- The branch root (`/`) is the runnable app and the Vercel preview is the user-facing artifact.
- `main` is only the neutral scaffold; generated work is never merged automatically.
- This repository must not contain credentials, private data, authenticated control-plane routes, or production integrations.
- Builds use the existing Claude and Codex subscription workers. Paid model APIs are disabled by default.
- A task is not complete until the app builds, the preview becomes reachable, and its requested behavior is verified.

## Local development

```bash
npm install
npm run dev
```
